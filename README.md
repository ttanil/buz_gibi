Buz Gibi 🐧❄️
Buz Gibi is a simple and fun Python-based children's game where players help a penguin break ice blocks while avoiding seals. To make a move, players must solve multiplication problems, combining learning with entertainment. The game is designed to be both educational and engaging for kids.

Features
Interactive Gameplay: Help the penguin navigate through ice blocks while avoiding seals.
Educational Element: Solve multiplication problems to make moves.
Simple Controls: Easy-to-understand mechanics suitable for children.
Fun Graphics: A playful environment with penguins, seals, and ice.
How to Play
Objective: Guide the penguin to safety by breaking ice blocks and avoiding seals.
Solve Multiplication Problems: Each move requires solving a multiplication problem. Correct answers allow the penguin to move forward.
Avoid Seals: Plan your moves carefully to avoid seals blocking the path.
Win the Game: Successfully navigate the penguin to the end of the ice field without getting caught by seals.
Technologies Used
Programming Language: Python
Libraries:
pygame (for game graphics and interactions)
random (for generating random obstacles and challenges)
Installation
Follow these steps to set up and play the game on your local machine:

Prerequisites
Python 3.x installed on your system
pygame library installed (you can install it using pip)
